# Learning Go + Personal Practice

This repository documents my journey of learning the Go language. The project is organized by topic. For each chapter, I study the theory and reinforce it by writing my own programs or solving practical problems.

## My Progress and Project Structure

**[FirstProgram](./FirstProgram)** — Basic syntax, Go program structure, and console output (Hello World and shapes printing).
**[Variables](./Variables)** — Data types, scope, and declaration types. 
    *My practice:* Wrote a car fuel consumption calculator involving type conversion (`int` to `float64`).
**[ConditionalBranching](./ConditionalBranching)** — `if`, `else if`, `else` statements and `switch` blocks.
    *My practice:* Exam score text status and leap year checker.
**[Cycles](./Cycles)** — `for` loop syntax, control statements (`break`, `continue`).
    *My practice:* Financial accumulation calculator and game HP/damage simulator.
**[Functions](./Functions)** — Function parameters, return values, and multiple return types in Go.

### Environment
Code is written and tested in a **Debian (WSL)** environment on Windows 10.

To run any topic, execute the following command from its folder:
```bash
go run main.go
```
