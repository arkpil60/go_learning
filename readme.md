# Learning Go + Personal Practice

This repository documents my journey of learning the Go language. The project is organized by topic. For each chapter, I study the theory from the course and reinforce it by writing my own program or solving a practical problem.

## My Progress and Project Structure

**[HelloWorld](./HelloWorld)** — Basic syntax, Go program structure, and console output.
**[Variables](./Variables)** — Data types, scope, and explicit vs. implicit declaration. 
*My practice:* Wrote a car fuel consumption calculator involving type conversion (`int` to `float64`).

### Environment
Code is written and tested in an **Ubuntu (WSL)** environment on Windows 11.
To run any topic, execute the following command from its folder:
```bash
go run main.go
```
